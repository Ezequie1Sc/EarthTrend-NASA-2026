Understanding the results

NASA POWER annual temperature reanalysis values are evaluated using linear regression. The estimated slope describes the direction and magnitude of temperature change per decade.

The R² coefficient indicates the proportion of observed variation explained by the linear model. Statistical significance is evaluated using a p-value threshold of 0.05.
